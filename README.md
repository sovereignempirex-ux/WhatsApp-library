## Vision

A reusable library that gives any WhatsApp bot project ready-made building blocks, instead of rewriting the same core features every time — connection handling, command routing, media utilities and crash protection out of the box.

## Roadmap

- [ ] Connection & session management
- [ ] Command router / dispatcher
- [ ] Media handling utilities (images, audio, stickers)
- [ ] Anti-crash & auto-restart layer
- [ ] Config system & multi-language support

> 🚧 Under construction — follow [VANITAS](https://github.com/sovereignempirex-ux) for updates.
